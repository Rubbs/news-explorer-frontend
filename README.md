# News Explorer (Frontend)

News Explorer is a frontend React application where users can search for news articles by keyword and save articles they like. This project was created as part of the TripleTen Software Engineering program and focuses on building a working frontend application.

## Live Demo

https://rubbs.github.io/news-explorer-frontend/

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- NewsAPI
- GitHub Pages

## What the App Does

- Allows users to search for news articles
- Shows search results on the page
- Lets users save and delete articles
- Saves articles in localStorage
- Includes a login and logout flow (mocked for frontend only)
- Works on desktop, tablet, and mobile screens

## Authentication

This project uses a mock authentication system for the frontend only.  
The login feature is used to demonstrate how protected pages work before a real backend is added.

## Deployment

The project is deployed using GitHub Pages.

## Notes

- This is a frontend-only project
- API keys are stored using environment variables
- The .env file is not included in the repository
